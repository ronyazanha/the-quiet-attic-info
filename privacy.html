Privacy and Google user data

Last updated: November 2, 2026. The Quiet Attic Publisher is a personal tool used by its owner to prepare and schedule lo-fi videos on the owner's YouTube channel.

Access and use

The application requests read-only Google Drive access to download its approved asset archive. This permission can technically read other files accessible to the authorized account; the worker is configured to download only the project archive. It requests YouTube read-only access to verify the target channel and existing uploads, and YouTube upload access to upload videos and set thumbnails. It uses this data solely to operate the owner's video production and scheduling workflow.

Storage and processing

Google OAuth credentials are stored as an encrypted secret in a private GitHub repository and supplied to a GitHub-hosted runner during execution. Media is downloaded and rendered in the runner's temporary workspace. Non-secret video IDs, titles, publication times and production history are retained in the private repository to prevent duplicate uploads. Source assets remain in the owner's private Google Drive, and completed videos are sent to YouTube with the owner's selected publication schedule.

Sharing

Google and GitHub process the information needed to provide their services. The application does not sell Google user data, use it for advertising, or send it to AI model training services. The videos and their public metadata become visible to YouTube viewers according to the owner's publication settings. This information website contains no sign-in form or analytics script; its hosting provider may retain ordinary request logs.

Owner controls

The owner can stop the GitHub workflow, revoke its access in Google Account third-party connections, remove the encrypted repository secret and delete retained project files or YouTube videos through the corresponding services. Revoking access stops future authorized API operations; it does not remove videos already uploaded.

The Quiet Attic Publisher's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

For support, use the owner account's support address shown on the Google consent screen.
