The Quiet Attic Publisher

A personal automation for the owner of The Quiet Attic lo-fi project on the YouTube channel @lofinoramilo.

The application reads approved music and animation assets from the owner's private Google Drive, combines them into one-hour study sessions, and uploads videos and thumbnails to the owner's authorized YouTube channel. YouTube schedules the completed videos for 06:00 in São Paulo.

Production runs in a private GitHub Actions repository. This is an owner-operated tool, not a public sign-up service.

Privacy and Google user data

Support: the owner account's support address is displayed on the Google consent screen.
